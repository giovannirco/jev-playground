Wary Gatekeeper

An AI agent has a plan for your cluster. Before anything runs, each command gets its own set of questions: does it only read, could it destroy something, does it match what you asked for, how big is the blast radius, does it expose secrets? The whole plan is checked in one call. Code turns the answers into run, confirm, or block. This is how you keep an agent on a leash without writing a thousand regexes.

Signals turn on after the check.
