How to read these sites

  • Choice picks one option from up to 255 and returns every probability.
  • Score places the state on an ordered rubric of up to 10 levels.
  • Noul is a yes/no, returned as the probability of yes.
  • All questions in a call are evaluated in parallel, which is why 200 questions cost about the same time as one.
  • Every site has an x-ray button showing the exact request and response.
The pages never call Jev on load. A call happens only when you use a page.
